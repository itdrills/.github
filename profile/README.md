IT Drills turns Kubernetes, DevOps, security and AI infrastructure topics into a training plan:
day by day, with drills, the expected output of every command, checkpoints, speed drills and a
challenge at the end of each day. Every course is tested on real machines, and all
43 courses are free, PDF and EPUB included.

This organization holds the companion repositories: the code, manifests and lab files you need
while working through a course. Each course is available in English and German.
